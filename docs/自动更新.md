# 自动更新怎么跑起来

自动更新链路是这样的：

```
打 tag → GitHub Actions 构建并签名 → 发布 Release + latest.json
                                            ↓
                          客户端读 tauri.conf.json 里的 endpoints
                                            ↓
                      用 pubkey 验证签名 → 通过才下载安装
```

签名这一环不能省。客户端只认用**对应私钥**签出来的包，验不过就拒绝安装——
这是防止别人往你的更新源里塞恶意包的唯一屏障。

---

## 一次性配置（三步，都要你自己做）

### 1. 生成签名密钥对

```bash
mkdir -p ~/.tauri
npx tauri signer generate -w ~/.tauri/agrec.key
```

会让你设一个密码（可以留空）。生成两个东西：

- `~/.tauri/agrec.key` —— **私钥，绝对不能进仓库**
- `~/.tauri/agrec.key.pub` —— 公钥

把公钥内容填进 `src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`，
替换掉现在那个 `REPLACE_WITH_PUBLIC_KEY_FROM_TAURI_SIGNER_GENERATE`。

> 私钥丢了 = 所有已安装的旧版本再也收不到更新（公钥对不上，新包一律被拒）。
> 备份到密码管理器里。

### 2. 把私钥交给 GitHub Actions

仓库 → Settings → Secrets and variables → Actions → New repository secret：

| 名称 | 值 |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | `cat ~/.tauri/agrec.key` 的完整内容 |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 上一步设的密码，没设就留空 |

### 3. 推送 workflow 文件

`.github/workflows/release.yml` 需要一个带 **workflow 权限**的令牌才能推上去。
用普通 token 推会被 GitHub 拒绝，报 `refusing to allow ... without workflow scope`。

去 GitHub → Settings → Developer settings → Personal access tokens，
新建一个勾选了 `repo` + `workflow` 的 token，然后用它推一次即可。

## 发一个版本

```bash
# 三个地方的版本号要一致
#   package.json                → "version"
#   src-tauri/Cargo.toml        → version
#   src-tauri/tauri.conf.json   → "version"

git commit -am "发布 v0.2.0"
git tag v0.2.0
git push && git push origin v0.2.0
```

然后去仓库的 Actions 页看构建。跑完会自动建好 Release，里面有 `.dmg`、
`.app.tar.gz` 和 `latest.json`。老版本的用户打开软件、点「设置 → 关于 → 检查更新」
就能看到新版本。

## 还没解决的一件事：Gatekeeper

CI 打出来的包用的是**临时签名**（ad-hoc），只对你自己够用。
别人下载后打开会被 macOS 拦下来，提示「无法打开，因为无法验证开发者」，
得右键 → 打开，或者去「隐私与安全性」里点「仍要打开」。

要让别人双击就能装，需要：

1. Apple Developer Program 账号（每年 99 美元）
2. 一张 **Developer ID Application** 证书
3. 构建后做**公证**（notarization）

配好之后在 workflow 里补上这几个 secret：
`APPLE_CERTIFICATE`、`APPLE_CERTIFICATE_PASSWORD`、`APPLE_SIGNING_IDENTITY`、
`APPLE_ID`、`APPLE_PASSWORD`、`APPLE_TEAM_ID`。

在只有自己和少数朋友用的阶段，可以先不花这个钱，在下载页写清楚
「首次打开请右键 → 打开」即可。用户量起来之前不值得。
